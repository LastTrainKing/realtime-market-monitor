## 安装

1. 允许「安装未知来源应用」；
2. 安装 APK；
3. 首次打开允许网络访问。

> 该 APK **未签名发布、未上架任何应用商店**。安装时系统可能给出安全提示，
> 这是正常的（未走应用商店签名的包都会这样）。

## ⚠️ 数据来源与风险

APK 内的 HTML 与网页版看板同源，**直接从设备请求东方财富接口**。
手机网络的出口 IP 与你的电脑不同，但**同样会受限流影响**。

详见 [../docs/data-source-risk.md](../docs/data-source-risk.md)。

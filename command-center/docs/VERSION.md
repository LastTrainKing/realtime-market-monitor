## 版本演进（问题驱动）

本项目的每个版本号都对应一轮**用户或评审提出的问题**，逐条可追溯：

| 版本 | 主题 | 关键内容 |
| --- | --- | --- |
| 0.1.0 | 首版 | 按规格书完成：Tauri 外壳 + React 前端 + Rust 后端 + SQLite；九榜、早盘节点、异动、复盘 |
| — | 第二轮（评审修复） | 资金曲线口径（板块相加重复计算）、候选样本重建语义、板块时间轴、事件计数重启归零、熔断单探针、血缘硬编码、E2E 脚本漏计失败、本地 API 鉴权 |
| — | 第三轮 | 历史静态分钟数据系统：Parquet + DuckDB、多日序列、校验、清单、增量补齐、粒度能力矩阵 |
| — | 第四轮 | 首页重排为四个核心模块，全部接入历史静态分钟库 |
| — | 第四轮续 | 补自动化渲染测试；修复测试隔离缺陷；排查出交付包内截图全为空白图并移除 |
| — | 第五轮 | 修正"主力资金累计曲线"口径标注（改为东财现成接口）；板块按 `data.total` 翻页取全 |
| — | 第六轮 | **删除"活跃股样本"第二股票池**（有偏样本，不可用于市场统计）；涨跌家数不足 3000 只时不展示数字 |
| **1.1.0** | **第七 / 八轮** | 界面显示版本号（此前无法判断装的是哪一版）；修正构建脚本挑错安装包；完成已安装版本的实际升级 |

> 为什么 0.1.0 之后一直没有改版本号：这是本项目的一个真实疏漏 ——
> 六轮修复期间后端始终上报 `0.1.0`，导致**无法从软件内部区分任何两个构建**，
> 用户因此把"装了旧版"误当成"修复没生效"。1.1.0 起已修正并加了回归测试。

## 重要说明：这些截图是 **v0.1.0（2026-10-01）** 的界面

* 它们**真实有效**（逐张统计不同颜色数在 7,800–12,500 之间，不是空白帧）。
* 但它们拍摄于**首版**，界面为当时的「市场全景」旧布局。
* **不代表 1.1.0 的界面**。1.1.0 与首版的差异包括：
  * 首页改为**四个核心模块**（① 指数分时 ② 主力资金累计曲线
    ③ 板块资金流入流出对比 ④ 时点数据面板），不再是「市场全景」；
  * 品牌区新增版本徽标 `v1.1.0`（首版显示 "AI Edition v0.1.0"）；
  * **不再存在"活跃股样本 1200 只"** —— 股票池只有一个全市场池（实测 5571 只）；
  * 涨跌家数从 584 / 605 修正为 2566 / 2830，成交额从 9614 亿修正为 14498 亿。

保留这些截图是为了**留档**，便于对照首版与当前版本的差异。

## 为什么没有 1.1.0 的截图

本机的构建环境无法采集 WebView2 画面：

* `PrintWindow(PW_RENDERFULLCONTENT)` 只能拿到窗口背景色（`#05070F`），不含网页内容；
* 桌面 DC `CopyFromScreen` 在应用全屏时整个桌面为单一颜色；
* 加 `--disable-features=CalculateNativeWinOcclusion --disable-gpu` 后仍然空白
  （WebView2 子进程确实已启动）。

对照实验：应用**关闭**时用同一种桌面 DC 采集能拿到 31,809 种颜色，
说明**采集方法本身没有问题**，是 WebView2 的画面没有被合成到桌面上。

因此交付包**不含 1.1.0 的运行截图** —— 宁可不给，也不给假图。
若需要，请在有可交互桌面会话的机器上执行：

```powershell
powershell -NoProfile -File scripts/capture-screenshots.ps1 -OutDir "<一个纯英文路径>"
```

脚本会按"采样色数 < 12"自动判定并**丢弃空白帧**，从机制上防止再产出假截图。

## 历史提醒（真实发生过的问题）

首版交付时曾用 `PrintWindow` 采集过一组页面截图，

空白图已全部删除，采集脚本也加了空帧检测。

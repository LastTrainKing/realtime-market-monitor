本次更新说明（v4.0.0 · 2026-09-25）
================================================

一、「无法连接数据源」—— 真实原因（已更正）
    不是你的网络问题，也不是 IP 被封，更不是接口被永久下线。

    实测结论：东方财富对这些接口会【间歇性断连】——
    服务器 TLS 握手成功后直接断开、不返回任何 HTTP 响应。
    而且不同接口在不同时间点被挡：

        接口                  15:5x        16:52
        fflow/kline（分钟）    断开         正常（连测 6 次全成功）
        clist（列表）          正常         断开
        ulist / trends2 / 日线  正常         正常

    也就是说：这是服务端对这个 IP 的临时拒绝，会轮换、会恢复。
    很可能的诱因：本软件原来每轮刷新要发 1000 个请求、30 秒一轮 ——
    这种访问模式极易触发临时限流。

二、换了采集链路：请求量降两个数量级
    旧：每个板块请求一次         → 1000 次/轮
    新：clist 拿当日累计，相邻两次相减还原区间值
                                → 约 10 次/轮
    盘中 4 小时按 60 秒算：约 48 万次/天 → 约 2400 次/天。
    面板口径不变（仍是每分钟区间值），历史数据可直接拼上。
    请求少了，触发限流的概率也就低得多。

三、非交易日 / 收盘后不再报「暂无数据」
    之前只判"现在几点"，没判"今天开不开市"。
    现在先问交易日历（今天 2026-09-25 中秋休市，日历里就没有这天）：
      · 非交易时段 → 采集【最近交易日的收盘静态值】，
        并如实标注"这不是分钟曲线"（早盘功能会拒绝用它，不拿一个点冒充曲线）
      · 要显示的交易日本地没有 → 自动退回本地实际有的最近一天，不再空白

四、窗口：启动即真全屏
    fullscreen=true + decorations=false + visible=false（状态就绪后再显示），
    不再有「普通窗口 → 最大化 → 全屏」的可见过渡。
    F11 / 全屏按钮可切换；只有你主动切过才会记住窗口模式。

五、错误提示能定位了
    以前所有连接失败都显示「无法连接数据源」。
    现在区分：DNS 失败 / TCP 失败 / TLS 失败 / 对方没返回内容 /
             403 拒绝 / 429 限流 / 当前不在盘中 / 未识别。

六、早盘功能支持历史回溯
    开盘检测（09:35/09:40/09:45）与九榜统计，晚启动也能从本地已有数据重建，
    不产生网络请求。

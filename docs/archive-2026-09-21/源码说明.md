# 资金流向 · 源码说明

> 最后更新：2026-09-23（v3.0.6 审计修复 + **延迟根因修复** + 事务式部署；候选构建 `dist_v306/`）

## 一句话

A 股全市场「板块资金流向 + 盘中辨识度」的纯原生桌面应用：
PySide6 界面 + matplotlib 原生绘图，**零浏览器内核**；
数据层纯标准库（东财公开接口），算法层复用 `core/`。

## 架构要点（改代码前必读）

1. **UI 单文件制**：所有界面代码在 `app_main_v203.py`；数据/算法在 `core/`，UI 通过
   QThread Worker 调用，绝不在 UI 线程做网络。
2. **★ 两级页签结构（v2.1.0）**：顶层 6 个**母模块**，母模块内部再用子页签承载子模块。
   ```
   总览            ← 单页，不打包（用户明确要求）
   大盘      ├ 市场全景 ├ 开盘检测
   个股      ├ 个股异动 ├ 个股精选
   资金排行  ├ 异动雷达 ├ 辨识度榜 ├ 行业概况 ├ 实时榜单
   板块题材  ├ 题材簇
   盘中复盘  ├ 实时事件 ├ 主角更替 ├ 阶段对比 ├ 关键节点
   ```
   **唯一权威来源是 `TAB_GROUPS`**（母模块 → 子模块列表）。三张派生的映射表：
   - `TAB_TREE`     母模块 → 子模块（与 TAB_GROUPS 同源）
   - `GROUP_INDEX`  母模块名 → 顶层下标
   - `GROUP_POS`    子模块名 → (顶层下标, 子页下标)
   - `PAGE_GROUP`   子模块名 → 母模块名
   - `PAGE_NAMES` / `PAGE_INDEX`  **保留为全部 14 个子模块的扁平清单**（旧接口兼容：
     Ctrl+N 的编号依据、chk115 的断言依据），不要删。
   启动时自动做三级自检并写日志：顶层序列、每个母模块的子页序列、
   子模块集合守恒（`tab tree OK: 6 groups · 14 modules all mounted`）。
3. **图表类工厂**：matplotlib import 实测 ~1s，7 个图表类由 `ensure_mpl()` 在
   窗口显示后按需定义（`_define_chart_classes`），画布由 `_materialize_charts()` 补建。
   ⚠ 任何直接使用 `FanChart` 等类名的脚本，必须先调 `ensure_mpl()`。
4. **图表归属按母模块**：`CHART_PAGE` 的值是**母模块名**（v2.1.0 起），因为
   母模块内部切子页时该图可能才第一次可见。改页签结构时这里必须同步。
5. **两段式首屏**：Worker 先 `early` 信号发本地面板旧数据，后台全量补抓后 `done` 发新数据；
   榜单池/归档/龙头只在最终版做一次。
6. **缓存全部按交易日命名**：`panel_YYYYMMDD.npy / opensnap_YYYYMMDD.json /
   watchlist_YYYYMMDD.json`，滚动保留 30 个交易日。

## 已知注意事项

- `build/core2/` 看着像垃圾实际是文件锁 workaround（tradecal 修正版），**必须随 datas 打包**；
- 打包 venv 若混入 pandas，exe 体积会 69.6MB → 92.5MB（matplotlib 可选依赖连带）；
  每次打包后核对 `_internal` 体积（正常 ~144MB / ~450 文件）；
- onedir 部署必须 exe 与 `_internal/` **成对**更新；
- 版本号只出现在窗口标题栏与「帮助→关于」；核对版本看日志 `preflight ok · vX` 行；
- **主源文件名与版本号已脱钩**：文件名仍是 `app_main_v203.py`（沿革），
  实际版本看文件内 `VERSION` 常量 —— 不要按文件名判断版本；
- `chk115.py` 是 v1.1.5 时代的旧回归套件，内部有大量针对**已删除功能**
  （`t_hover` 悬停面板、9 张交付截图等）的断言，直接跑会在 C 段中断。
  判断页面结构是否正常请用 `verify_v210_structure.py`（专项、不依赖旧套件）。
  ★ 该文件已于 v2.1.0 修正为加载**实际打包的主源文件**（此前长期加载同目录的
  遗留副本 `native_app.py`，导致测试与交付物脱钩、给出虚假的全绿）；
- `native_app.py` / `native_app.py.new` 是历史遗留副本，**不参与打包**，
  但 chk115 曾依赖它 —— 已改为按 spec 口径加载 `app_main_v203.py`。

# Shell 版（无数据读取能力）

> 本文说明 `flowlive-native` 的 **Shell 形态**：为什么做、做了什么、怎么验收、怎么用。

---

## 一、为什么做这个版本

原版的取数层直连东方财富 `push2` 集群。上游已对该来源做**风控标记**，
任何使用该功能的机器都会面临 **IP 被接口封禁** 的风险——这已不是"能不能用"的问题，
而是"用了会伤到使用者"的问题。

因此发布一个**不具备数据读取能力**的版本：保留界面、算法、复盘能力，
移除全部联网取数实现。

---

## 二、两种形态

同一套代码，用环境变量切换：

| 形态 | 环境变量 | 能力 |
|---|---|---|
| **离线复盘终端**（默认） | `FLOWLIVE_SHELL_MODE=replay` | 可导入本地文件、回放历史、跑全部算法、导出报告 |
| **纯空壳** | `FLOWLIVE_SHELL_MODE=pure` | 只保留界面与算法，**不提供导入入口**，无任何数据 |

```bash
# 离线复盘终端
set FLOWLIVE_SHELL_MODE=replay

# 纯空壳
set FLOWLIVE_SHELL_MODE=pure
```

默认是 `replay`。理由：一个什么都干不了的壳没有使用价值，也无法验证算法层是否还活着。

## 四、为什么不是"把数据层整个删掉"

因为 UI 和算法都依赖数据层输出的 `Panel` / `Snapshot` 结构。
直接删掉，程序启动即崩。

正确做法是**换实现，不砍层**：保留函数签名，把行为改成"读本地"。
这样上层一行不用改，程序照常启动、照常渲染、照常跑算法——只是不再联网。

这也是当初做多源抽象层的红利：数据访问本来就收敛在 `source.py` 一个工厂后面。

## 五、怎么验收"真的没有取数能力"

### 5.1 静态检查（自动）

```bash
python scripts/check_no_network.py .
```

检查三条，任一不通过即退出码 1：

1. 运行时代码（`core/`、`core2/`、`app_main_v203.py`）不得 import 任何网络库
   （urllib / http.client / socket / ssl / requests / httpx / aiohttp …）
2. 运行时代码不得出现 `http(s)://` 字面量
3. 若有 `Cargo.toml`，不得依赖 reqwest / hyper / ureq 等 HTTP 客户端

**当前状态：通过（15 个文件，0 违规）。**

### 5.2 动态验证（需人工）

| 方法 | 通过标准 |
|---|---|
| 断网启动 | 全功能可用，界面不报错 |
| 联网启动 + 抓包 | 进程生命周期内 **0 个出站请求** |
| 系统防火墙全阻断该进程 | 与联网时行为一致 |

> 动态验证需要在目标机器上跑，仓库里无法自动完成。

## 六、数据从哪来（离线复盘终端）

`core/localio.py` 提供三个入口：

### 6.1 导入 CSV

必需三列，列名支持多种别名：

| 语义 | 可用列名 |
|---|---|
| 时间 | `时间` / `time` / `分钟` / `hm` / `时刻` |
| 代码 | `板块代码` / `代码` / `code` / `secid` |
| 数值 | `主力净额` / `主力净流入` / `净额` / `net` / `value` |

可选列：`板块名称` / `name`、`类型` / `kind`。

```python
import localio
meta, mat = localio.import_csv("我的数据_20261030.csv", tag="20261030")
```

时间支持 `0931` / `9:31` / `09:31:00` 三种写法，统一规范成 `09:31`；
代码支持 `BK1036` / `90.BK1036`，统一补成 `90.BK1036`。

### 6.2 导入 JSON

```json
{
  "meta": {
    "times": ["09:31", "09:32"],
    "codes": ["90.BK1036", "90.BK1202"],
    "names": {"90.BK1036": "半导体"},
    "kinds": {"90.BK1036": "concept"},
    "data_date": "20261030"
  },
  "values": [[1.5e8, -3e7], [2.1e8, -2.8e7]]
}
```

`values` 形状必须等于 `(len(times), len(codes))`，否则报错并给出期望形状。

### 6.3 回放已有缓存

历史版本落盘的 `panel_YYYYMMDD.npy + .json` 可直接回放，无需转换。

```python
import localio
for tag, date, rows, cols, src in localio.list_panels():
    print(tag, date, f"{rows}分钟 x {cols}板块", src)
```

## 七、已知限制

1. **没有分钟级资金流历史**——原版靠联网取，现在只能靠导入。
2. **板块成分股 / 全市场个股快照 / 龙头分析**依赖的成分股数据不可用，相关模块会跳过。
3. **交易日历只读本地缓存**，缓存过期后按工作日推算兜底。
4. 打包仍需在目标机器上进行（PyInstaller + PySide6 环境），本仓库不产出 exe。

资金流向实时看板 —— 使用说明
========================================

【怎么打开】
  双击桌面上的「资金流向看板」图标即可，会像一个独立软件那样开一个窗口。

  · 不需要安装任何东西（不用 Python、不用插件）
  · 不需要联网部署、不需要登录
  · 数据全部在你本机浏览器里处理，不会上传到任何地方

  如果桌面图标不见了，也可以双击本文件夹里的「资金流向看板.html」，
  但请务必用 Edge 或 Chrome 打开，不要用 Firefox（原因见下方常见问题）。


【它会自动显示哪一天】（不用你手动切）
  · 非交易时段打开   → 显示最近一个交易日的完整盘中数据
                       例：9 月 18 日凌晨打开，显示的是 9 月 17 日
  · 交易日 09:30 开盘 → 自动切换到当天，并每 5 秒实时刷新
  · 11:30–13:00 休市 → 停留在当天上午的数据，13:00 自动恢复刷新
  · 15:00 收盘后      → 停留在当天，显示全天完整数据
  · 周末与节假日      → 自动显示最近一个交易日


【界面怎么看】
  （模块自上而下依次排列，每个模块独占一行，互不挤占）
  · 顶部      ：数据日期 / 当前时段 / 是否实时 / 两个指数
                  上证指数 3875.60（只反映上交所）
                  东财全A 6452.87（覆盖沪深全市场，更能代表大盘）
                  两个指数并列，方便对比"沪市 vs 全市场"的强弱差异
  · 主力资金曲线：每个题材一条线，从开盘原点发散；
                  末端是「题材名 + 累计主力净额（亿元）」
                  红 = 净流入，绿 = 净流出
  · 板块辨识度榜：当下资金最集中的题材（左列净流入、右列净流出各 15 条）。
                  每行只含 净额 / 近5分钟 / 排名 / 辨识度 四列，干净清爽。
                  「10min跃迁」「z」已从表格去掉；这两项数据仍在后台参与
                  事件判定与排序，只是不再占表格位置
  · 一级行业格局：31 个一级行业里谁在吸金、谁在失血（各 8 条）。
                  列与上面的题材榜完全一致，且**列宽已锁死**，
                  所以左右两栏 + 上下两张表的数值列严格对齐，不会有"歪"的感觉
  · 实时事件  ：独占一整行、左右两栏平铺（共 12 条），只看「此刻」发生了什么，
                  类型有 新晋 / 加速流入 / 加速流出 / 排名跃迁 / 持续强势 /
                  持续失血 / 资金回流 / 资金撤离 / 逆向吸筹 / 借涨出货
  · 全天关键节点榜：把一整天从头到尾扫一遍（每 5 分钟一个采样点），
                  按强度排序、同一题材只留最强的一条，共约 24 条。
                  这是"今天一整天最值得记住的几个时刻"，
                  和上面的「实时事件」互补（一个看此刻、一个看全天）
  · 主线题材簇：独占一整行、按 4 列平铺，显示资金正在集中做哪条线、由哪几个子题材组成
  · 龙头领先反应：给每个在榜板块自动标注「领涨龙头 / 领跌龙头」。
                  判定标准不是"净额最大"，而是**在板块点火/跳水拐点上先动手的那只**：
                    · 拐点：对板块分钟资金流做 3 分钟平滑，用 MAD 自适应阈值找
                      "平淡→放量"的转向点（点火/跳水），同类相邻拐点合并为一次事件
                    · 领先：个股在拐点前 10 分钟内出现同向显著反应的最早分钟
                      领先分钟 = 拐点时刻 − 个股反应时刻（正数＝个股领先）
                    · 评分 = 1.8×领先幅度 + 1.0×先手率 + 0.7×响应幅度 + 0.5×自有净额
                    · 点火/跳水两个方向分别排名，所以涨跌龙头通常不是同一只
                  板块的龙头只集中显示在下方「龙头领先反应」面板里，包括：
                    板块名 / 板块净额 / 领涨龙头 / 领先与先手 / 领跌龙头 /
                    依据（拐点数 + 各拐点领先分钟）
                  例如国产芯片那一行：领涨龙头 华天科技，领先 6.8′、先手 2/2，
                  依据「拐点2个（点2/跳0）· 涨：10:03↑+3′ 10:35↑+10′」
                  —— 即板块 10:03 点火时它领先 3 分钟动手、10:35 点火时领先 10 分钟。
                  榜单表格里不再重复显示龙头（避免占宽、看着乱）。
                  首次分析约 10~25 秒，之后每 5 分钟自动更新，也可点「重新分析龙头」。
                  实测：9/18 半导体概念的领涨龙头是华天科技（涨停 +10.01%、
                  占板块主力 41.3%），在 09:39/10:03/10:36 三次点火上分别领先 7/3/10 分钟。
  · 主角更替时间轴：两种视图，右上角按钮一键切换。
      默认「逐格视图」：每 10 分钟一格，横向按时间等距排列，
                        三行是该时刻辨识度第 1/2/3 名 —— 可精确核对
                        「10:20 那一刻谁在当主角」。
      点一下切到「时长视图」：格子宽度＝该题材当主角的时长，
                        能一眼看出「谁主导了多长时间」。
      两种视图互补：逐格看某一刻，时长看整体格局。
  · 阶段对比：把一天切成 09:45 / 10:30 / 11:30 / 13:30 / 14:15 / 15:00 六个时点，
                  每格列出该时点辨识度最高的 6 个流入（上排红）和 6 个流出（下排绿）题材。
                  用来横向比较"早盘炒什么、午后换成什么、尾盘又在做什么"。
  · 辨识度时间轴：每个题材一整天的资金轨迹。
                  看某一行由红转绿的时刻，就是资金从流入转向流出的拐点


【收盘数据会自己攒起来（滚动 30 个交易日）】
  · 每个交易日收盘后，当天数据会自动存一条到本地（不上传）
  · 只保留最近 30 个交易日；从第 31 天开始，新的一天会把最早的一天挤掉
  · 页面下方「近 30 个交易日」表格里能看到每天：
    星期 / 上证收盘 / 涨跌幅 / 最强行业 / 最强题材 / 最弱行业 / 最弱题材 / 主线，
    点右侧「查看」可回看那天的收盘数据。
    注意「行业」和「题材」是两个层级，分开列：
      · 行业 = 31 个一级行业（汽车、电子、医药生物…）
      · 题材 = 概念题材（智谱AI概念、光模块、存储芯片…）
    两者常不同——例如 9/17 行业第一是"汽车 +37.08"，题材第一是"智谱AI概念 +27.36"，
    分两栏就都能看到
    （回看时顶栏会显示「历史回看」，点「返回实时」即可回来）
  · 表格右上角有「运行功能自检」按钮，会实时验证
    「非交易日回退」与「30 日滚动窗口」两条规则，当前 30/30 通过

【非交易日会显示哪一天】
  · 周六 / 周日       → 显示周五的收盘数据
  · 节假日            → 显示节前最后一个交易日的收盘数据
  · 交易日开盘前      → 显示昨天（上一个交易日）的收盘数据
  · 交易日 09:30 之后  → 显示当天并实时刷新
  · 判断依据是数据源返回的"最近一个有数据的交易日"，不需要人工维护节假日日历
  · 顶栏「数据日期」徽章 + 状态徽章 + 提示条三处都会写明当前展示的是哪一天


【曲线为什么有时会出现垂直跳变？已修复】
  曾经出现过两条曲线在某一点垂直飙高又回落。查证结论：
    · 原始接口数据是干净的（962 个板块全量扫描：0 尖刺、0 处超 15 亿跳变）
    · 跳变是三个使用侧原因造成的：
      ① K 线比时间轴少一分钟时，末槽残留占位值 0（最主要，实测 27/427 条曲线命中了）
      ② 时间轴在两次 K 线刷新之间不前进，快照却把"当前值"写进上一分钟的槽位
      ③ 数据源会间歇性返回滞后约 4 分钟的旧值，与实时值交替
  已全部修复，并新增「数据校验与清洗」面板：
    · 绘制前统一校验：时间轴等距/重复、缺失值、单点尖刺、阶跃跳变、
      累计值重置、量级越界
    · 修正方式不丢弃数据：尖刺用邻点插值、阶跃摊回前几分钟（端点与总量不变）
    · 阈值全部可配置，面板上能直接改，改完立刻生效
    · 逐条列出「时刻 / 板块 / 异常类型 / 跳变幅度 / 修正前 / 修正后 / 处理方式」
    · 可一键导出 CSV 清单；也可以取消勾选「启用清洗」看修复前的样子做对比
  实测：全样本最大相邻跳变 24.81 亿 → 8.50 亿（8.50 正是原始数据的自然最大值），
        含 0 占位曲线 27 条 → 0 条。


【刷新频率】
  盘中：每 5 秒刷新一次实时数值；每 10 分钟后台回补一次完整曲线
  非盘中：每 20 秒检查一次是否开盘（不做多余请求）
  右上角也有「立即刷新」按钮可手动触发


【首次打开会慢一点】
  要拉取全市场约 1000 个板块的分时数据，约 5–15 秒（顶部有进度条）。
  同一天再次打开会直接读本地缓存，秒开。


【常见问题】
  Q：必须装 Python 吗？
  A：不用。这就是一个网页文件，零环境依赖。

  Q：数据从哪来？
  A：东方财富公开接口（板块分时资金流、板块快照、指数分时）。

  Q：用 Firefox 打开行不行？
  A：不行。Firefox 默认禁止本地文件页面读取网络数据，会看不到数据。
     请用 Edge / Chrome 打开，或直接双击桌面快捷方式。

  Q：金额是什么口径？
  A：「主力净流入」按东方财富定义 = 超大单 + 大单净额。
     各板块成分股互相重叠，跨板块加总不能当作全市场总额，
     只适合做板块之间的相对比较。

  Q：打不开 / 白屏 / 没有数据？
  A：先确认能上网，然后重新双击一次快捷方式。
     页面顶部会显示当前状态与错误原因。

  Q：看到的是哪天的数据？会不会看错？
  A：不会。顶部「数据日期」徽章就是当前展示的交易日，
     并会明确标注「盘中实时」还是「非实时 · 展示最近交易日」。

资金流向 · 手机版（APK）安装与使用说明
========================================================

一、这是什么
--------------------------------------------------------
把桌面上的「资金流向实时看板」打包成了一个独立的安卓 App。

  · 应用名：资金流向（桌面图标下显示的就是这四个字）
  · 应用图标：与原桌面快捷方式同一个图标（已内置 5 档分辨率）
  · 包名：com.abu.flowlive
  · 支持系统：Android 5.0 及以上（minSdk 21）
  · 权限：仅「网络访问」一项
  · 签名：v1 + v2 + v3（apksigner）

装上后手机上点图标即可看盘中资金流向，不需要电脑、不需要开浏览器、
不需要任何后台服务。

关于「桌面快捷方式」：Windows 的 .lnk 在手机上无法使用，所以没有打包进去。
它的等价物就是装好后桌面自动出现的那个应用图标 —— 图标样式沿用原快捷方式的
那个，名字叫「资金流向」，点它即开。


二、两个版本，先用第一个
--------------------------------------------------------

  ① 资金流向.apk            ← 首选，先用这个
     targetSdk 34（Android 14 目标版本）
     现代系统上行为最规范

  ② 资金流向_兼容版.apk     ← ①装不上时再试这个
     targetSdk 29（Android 10 目标版本）
     兼容性更宽松，老系统 / 特殊 ROM 更容易接受

两个版本功能、界面、数据完全一致，图标与名称也相同，只有 targetSdkVersion 不同。
只用装其中一个，装成功一个就够了，另一个可以删掉。

（targetSdk 决定系统以哪一版 Android 的行为规范运行这个应用。
  对 WebView 壳应用没有功能差别。）


三、怎么装到手机上（三种方法，任选）
--------------------------------------------------------

方法 A：微信 / QQ 传（最方便）
  1. 电脑微信 →「文件传输助手」→ 把 APK 发过去
  2. 手机上点开该文件 → 直接点「安装」
  3. 若提示禁止安装，点提示里的「设置」→ 打开
     「允许来自此来源的应用」→ 返回 → 再点安装

方法 B：用数据线
  1. 把 APK 拷到手机任意目录（如「下载」）
  2. 用「文件管理」找到它，点击安装

方法 C：网盘
  上传后用手机端下载、点开安装。

★ 「允许安装」入口各家名称不同：
   小米/红米：设置 → 应用设置 → 应用管理 → 权限管理 → 安装未知应用
   华为/荣耀：设置 → 安全 → 更多安全设置 → 外部来源应用下载
   OPPO/一加：设置 → 其他设置 → 设备与隐私 → 安装外部来源应用
   vivo/iQOO：设置 → 更多设置 → 权限管理 → 安装未知应用
   三星：设置 → 安全与隐私 → 安装未知应用
   原生 Android / 模拟器：设置 → 应用 → 特殊应用权限 → 安装未知应用

★ 首次打开可能提示「此应用未经 Google Play Protect 验证」或
   「未知开发者」，选择「仍要安装 / 继续」即可。
   这是所有非商店渠道 APK 的正常提示，不是包有问题。


四、如果还是装不上，按这个顺序排查
--------------------------------------------------------

1) 换另一个版本试
   ① 装不上 → 试 ②「兼容版」。两者签名方案不同，能覆盖不同系统策略。

2) 看具体报错文字，对症处理
   · 「解析包错误 / 解析软件包时出现问题」
       → 文件传输损坏。重新传一次（微信传输请选「原文件」，
         不要用聊天里的预览/压缩版本）。
   · 「应用未安装 / 未安装该应用」
       → 先卸载手机上任何同名旧版本，再装。
   · 「无法验证应用 / 该应用可能有害」
       → Play Protect 拦截。选「仍要安装」；
         若被强制阻止：设置 → Google → Play Protect → 关闭「扫描应用」。
   · 「设备不安全 / 已被阻止」
       → 部分国产 ROM 的「纯净模式」在拦。设置里关掉纯净模式再装。
   · 「与您的手机不兼容」
       → 系统低于 Android 5.0（罕见）。

3) 用 adb 拿准确错误（能连电脑时最准）
   手机开「开发者选项 → USB 调试」，电脑上执行：
       adb install -r "资金流向看板.apk"
   屏幕会直接打印失败原因（INSTALL_* 错误码），比手机提示详细得多。

4) 厂商安全检测
   小米/华为/OPPO 安装非商店应用时可能弹「安全检测」，一般可「继续安装」跳过。


五、本包的已知边界（诚实说明）
--------------------------------------------------------
· 图标与名称已内置：APK 含 res/ 资源（5 档密度的启动图标 + 应用名），
  装好后桌面显示的就是「资金流向」这个名字与原来的图标。
· 未在真机上实测：本次构建通过 Android 官方工具验证 ——
  aapt2 编译资源并解析出图标与名称、apksigner 校验 v1/v2/v3 签名、
  zipalign 校验 4 字节对齐（含 resources.arsc）、dexdump 解析 DEX，
  并穷尽了 Android 安装器的全部已知拒绝条件（61/61 项通过）。
  但没有跑真机安装：本机从 Google 下载模拟器系统镜像只有 0.2~0.6 MB/s，
  且需要硬件虚拟化支持，成本过高。
  若仍装不上，请按第四节把报错文字发我，能直接定位。


六、装上之后怎么用
--------------------------------------------------------
1. 点图标打开，首次显示「正在初始化…」并拉取数据
2. 首次全量拉取约 400 个板块的分钟数据：WiFi 约 10~30 秒，4G/5G 稍慢；
   之后数据缓存在手机本地，再打开即秒开
3. 交易时段自动刷新；收盘后显示当日完整数据

界面与电脑版完全一致，自上而下：
  主力资金曲线 / 板块辨识度榜 / 一级行业概况 / 实时事件 /
  主线题材簇 / 全天关键节点榜 / 主角更替时间轴 /
  板块辨识度时间轴 / 龙头领先反应 / 数据校验与清洗 / 阶段对比 /
  近 30 个交易日时间表 / 功能自检

手机上的操作提示：
  · **版面已按手机重排，从头到尾都不需要左右拖动**
  · 主力资金曲线：板块名不再挤在曲线右侧（右侧放不下），
    改为**图下方的图例** —— 色块 + 板块名 + 累计净额，自动换行铺满整行
  · 板块辨识度榜：纵向卡片，每行一张卡（排名 / 题材名+条形 / 净额，
    下一行是 5min、排名、辨识度）
  · 全天关键节点榜：卡片式，每张卡两行（时刻+事件+题材+强度 / 完整说明）
  · 龙头领先反应：卡片式，不再横向滚动（板块+净额 / 领涨 / 领跌 / 拐点依据）
  · 主角更替时间轴：逐格视图左侧为「1名/2名/3名」，格子间距已拉开、
    时刻标签居中加粗；点「切换为时长视图」可换成泳道图
  · 阶段对比：6 个时点 2 列排列，条形与数值不再重叠
  · 面板说明文字自动折叠为两行，不挤占内容
  · 双指缩放可放大细节
  · 看盘时屏幕不会自动黑屏
  · 返回键：页面内可后退则后退，否则退出应用

说明：以下三项在手机端不展示，桌面版仍保留 ——
  · 「数据校验与清洗」面板（清洗逻辑仍在后台照常运行）
  · 「数据源、字段与算法说明」折叠块（需要时可在电脑上打开查看）

注意事项：
  · 必须联网。数据来自东方财富公开行情接口。
  · 数据存在应用内部存储，清除应用数据或卸载重装会清空
    那 30 个交易日的历史归档。
  · 归档每天约 90 KB，30 天约 2.7 MB，手机本地存储（约 5 MB）够用；
    超出时程序会自动降级保留摘要。


七、重建方式（电脑版更新后）
--------------------------------------------------------
工程与脚本：C:\Users\user\WorkBuddy\2026-09-17-23-56-54\work\apk_build\

  setup_env.py            下载 JDK + android.jar + d8.jar（一次性）
  repair_env.py           按名提取上述组件（不解压无关文件）
  add_icon_and_res.py     从 icon.ico 生成各密度图标 + res/values/strings.xml
                          + 文本 AndroidManifest.xml
  build_app_res.py        ★ 主构建：aapt2 编译资源 + 打包 + 对齐 + 签名
                          可用环境变量切换：
                            TARGET_SDK=29 APK_NAME=资金流向_兼容版 \
                            OUT_DIR=build_output_res_c29  python build_app_res.py
  build_app.py            旧版构建（无 res/ 资源，仅手写 manifest）
  verify_apk.py           多层校验（zip / DEX / 签名方案 / aapt2 / 解析器）
  verify_install_ready.py 安装就绪度检查（穷尽安装器拒绝条件）
  mobile_check.py         手机视口下的版面与功能验证
  android-project\        Android 工程
                          ├─ app/src/main/AndroidManifest.xml   （文本，aapt2 编译）
                          ├─ app/src/main/res/mipmap-*/         （5 档图标）
                          ├─ app/src/main/res/values/strings.xml（应用名）
                          ├─ app/src/main/java/…/MainActivity.java
                          └─ app/src/main/assets/www/index.html

三条构建要点（都踩过）：
  ① 顺序必须是「aapt2 link → 组装 → zipalign → apksigner 签名」——
     v2/v3 签名覆盖整个文件，签名后再对齐会破坏签名。
  ② 签名必须用 apksigner（v1+v2+v3），不能用 jarsigner（只有 v1）——
     targetSdk >= 30 时 Android 11+ 会拒绝只有 v1 签名的 APK。
  ③ resources.arsc 必须 STORED 且 4 字节对齐（targetSdk >= 30 的硬要求），
     所以组装 zip 时要强制它不压缩，再由 zipalign 保证对齐。

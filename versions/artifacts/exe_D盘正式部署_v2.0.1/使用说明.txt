================================================================================
  资金流向 · 纯原生桌面版 v2.0.1 —— 使用说明
================================================================================

【怎么用】

  直接双击「资金流向原生版.exe」即可，无需安装。

  ★ 整个文件夹都要保留（exe 和 _internal\ 必须在一起）：
    这是 onedir 形态，exe 只是个入口，真正的依赖都在 _internal\ 里。
    只拷 exe 出去是跑不起来的。


【历史数据在哪】

  就在本文件夹里 —— 和 exe 同级：

    资金流向原生版.exe
    _internal\      运行依赖（别删）
    data\           ★ 历史交易日数据、面板、自选清单、快照龙头
    logs\           运行日志（排查问题看这里）
    shots\          自检截图

  备份只需要整个复制文件夹。
  数据全是明文（.json 和 .npy），可以拷到别的机器接着用。

  ★ 判定规则：程序启动时看自己身边有没有一个**有内容的 data 目录**。
    有 → 认定这是"便携部署"，所有数据就近写在自己旁边；
    没有 → 回落到 C 盘的用户目录（%LOCALAPPDATA%\FlowLiveNative）。
    所以「把文件夹连同 data 一起拷到 U 盘」是可行的：拷过去就是便携的。


【怎么判断数据确实写在这里】

  打开 logs\app_日期.log，最后一行 preflight 会写明程序根目录，例如：

    preflight ok · v2.0.1 · frozen=True · BASE=D:\exe\_internal

  其中 BASE 前面的那一层（这里就是 D:\exe\）就是数据落点，
  data\ / logs\ / shots\ 都在它下面。

  ★ 如果哪天觉得"日志没更新"，用这个参数让程序把路径判定结果打出来：
    资金流向原生版.exe --shot diag
    输出里的 [diag] 段会列出 portable_root / app_home / log 的实际取值，
    并做一次真实的写测试（[diag] log write test=OK / FAILED）。


【v2.0.1 相比上一版的变化（用户需知的部分）】

  ★ 刷新 = 取最新
      以前「刷新」只读本地缓存，盘中看到的是几分钟前的数据，
      必须点「重新抓取」才会更新 —— 现在合并成一个动作：
        · 交易时段：走增量刷新（约 0.35 秒），拿到的就是当前这一分钟；
        · 非交易时段：直接读本地数据（盘中无新数据，不必空跑网络）。
      「重新抓取」按钮已按你的要求从界面移除。

  ★ 状态栏会告诉你数据有多新
      例如：就绪 · 427 个板块 · 240 个分钟点 · 分时到 15:00 ·
            数据 2026-09-21（实盘） · 更新于 21:26:29
      「分时到」= 数据本身到哪一分钟；「更新于」= 本次上屏时刻。

  ★ 首屏更快
      打开程序时只绘制当前这一页的图表，其余页在你切过去时再画
      （实测首屏绘图从 1314ms 降到约 330ms）。

  ★ 新增两页
      · 市场全景 —— 指数分时（上证 + 东财全A）、主力资金流入/流出对比、
                     时点数据面板（整宽）。
                     「总览」页因此只留 KPI 卡行 + 放大的主力资金累计曲线
                     （曲线高度约为原来的两倍），20 条线更容易看清。
      · 异动雷达 —— 高召回地列出"此刻动作异常"的板块。
                     四项指标全部取横截面分位（z 突异 / 速度异动 /
                     排名跃迁 / 尾盘资金回流），**不依赖任何板块名单**，
                     新出现的题材只要有异动就会自动进来。
                     每行给出「识别原因」，说明它被哪一维选中。

  ★ 排序方向改为「从晚到早」
      全天关键节点、实时事件两页现在都是最新的排在最上面
      （9:50 的事件显示在 10:20 的下方）。

  ★ 实时榜单页
      · 「板块概念实时榜单」新增「龙头选手」列（该板块当下的领涨股）；
      · 下半部分扩为四个模块：
          当下辨识度榜·流入 / ·流出 / ·五分钟净流入 / ·五分钟净流出。
        「五分钟」两张按近 5 分钟增量排序，回答"此刻钱在往哪去"。

  ★ 算法：能筛出以前看不到的板块
      以前事件检测只在"|中性化增量| 前 80 个"板块里找，概念层覆盖率仅 18.7%，
      细分方向（光纤/光模块/PCB/存储/先进封装…）常连候选都进不去。
      现在改为全量扫描 + 分位门槛，并新增「尾盘资金回流」事件类型。
      实测：你点名的 32 个方向里，面板确实有对应板块的 27 个，覆盖从 11 个提升到 25 个。

  ★ 其他
      · 补齐了窗口/任务栏图标（以前只有文件图标，用起来到处没图标）；
      · 修正了总览顶部 KPI 卡片大字体被裁切的问题；
      · 版本号 v2.0.1（窗口标题栏与「帮助 → 关于」都能看到）。


【常用命令行参数】

  资金流向原生版.exe --shot 前缀名
      无人值守自检：逐页截图到 shots\ 然后自动退出。不弹窗。
      ★ 同时会把每页**表格里的真实文字**导出成同名 .txt（便于核对排序）。

  资金流向原生版.exe --shot 前缀名 --date 20260918
      同上，但先把界面切到指定历史交易日再截图。

  资金流向原生版.exe --shot diag
      路径诊断：把"数据/日志/截图到底写在哪"打到输出里，并验证可写。

  这些都平时用不到，留作"确认程序还正常"的快速体检手段。


【常见问题】

  问：双击没反应？
  答：检查 exe 是否和 _internal\ 在一起。另外程序有单实例限制，
      已经开着一个时再双击会静默退出（这是设计，避免两份同时抓数据）。
      单实例的判断依据是本文件夹里的 app.lock。

  问：提示"程序组件不完整，无法运行"？
  答：_internal\ 缺失或被安全软件删了。重新完整复制一遍文件夹。

  问：想彻底重置数据？
  答：删掉 data\ 文件夹即可（程序会自动重建）。想保留历史就先备份。

  问：日志文件一直是空的 / 不更新？
  答：把 logs\ 里的旧日志删掉（或改名）再启动。
      已知道一种情况：某个旧日志文件可能处于"新进程无法追加"的状态，
      删掉后程序就能正常重建。（v2.0.1 的 log_line 已加降级：
      主日志写不进去会自动改用 app_日期.1.log，不会静默丢日志。）

  问：「龙头选手」列显示「—」？
  答：该列数据来自盘中快照，需要一次联网刷新才会填充。
      如果刚打开程序还没刷新过（或数据源临时限流），就会显示「—」——
      这是"没有数据"，不是程序出错。盘中正常情况下每 30 秒刷新一次。

  问：能放在 U 盘里用吗？
  答：可以。整个文件夹搬走即可，数据跟着走。
      唯一差别是 FAT32 单文件上限 4GB，本程序最大的文件也就 20MB 左右。
